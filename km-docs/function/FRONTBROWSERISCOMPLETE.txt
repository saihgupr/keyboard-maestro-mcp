====== FRONTBROWSERISCOMPLETE Function ======

The FRONTBROWSERISCOMPLETE() function (v8+) returns 1 if the active tab of the front browser (the most recently front web browser of Safari or Google Chrome) has completed loading (as far as Keyboard Maestro can tell), and 0 otherwise.
