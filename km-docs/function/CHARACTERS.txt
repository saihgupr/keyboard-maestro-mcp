====== CHARACTERS Function ======

The CHARACTERS(t) function takes an arbitrary [[:Tokens|token text]] string, processes the text tokens, and then returns the number of characters in the string.

    CHARACTERS(%CurrentClipboard%)
    CHARACTERS(%Variable%MyVar%)
