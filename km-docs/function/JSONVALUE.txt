====== JSONVALUE Function ======

The //JSONVALUE(t)// function takes a [[:manual:JSON#JSON_Paths|JSON path]] and returns the numeric result.

`JSONVALUE(jsonpath)` is more or less equivalent to `CALCULATE(%JSONValue%jsonpath%)`.

===== Examples =====

If a Keyboard Maestro variable `J` contains the JSON object:

    {"a":9, "b":"bravo", "c":null, "d":[11,"two",33]}

Then these would be the results:

^ Token ^ Result ^ Comment ^
| `JSONVALUE(J.a)` | `9` | |
| `JSONVALUE(J.d[1])` | `11` | |
| `JSONVALUE(J.d[3])` | `33` | |
| `JSONVALUE(J.d[1+2])` | `33` | entry 3 |
| `JSONVALUE(J.d[0])` | `3` | the number of entries in the array |
| `JSONVALUE(J.d[-1])` | `33` | the last entry |
| `JSONVALUE(J.d[COUNT()])` | `33` | the last entry |
