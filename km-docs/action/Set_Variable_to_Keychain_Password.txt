The Set Variable to Keychain Password action sets a variable to a generic password value from the Keychain.

:!: This action does //not// work with Internet Passwords – only with Generic Passwords.

{{:action:setvariabletokeychainpassword.png|}}

Text areas in this action can be set by typing a value or by selecting a value from the arrow at the right-hand end of the text area.

You must supply:
  *The variable to receive the keychain password.
  *The name of the keychain item.
  *The account able to use that password.
