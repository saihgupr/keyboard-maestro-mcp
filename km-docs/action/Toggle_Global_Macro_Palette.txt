====== Hide/Show Global Macro Palette Actions ======

The //Show Global Macro Palette// action shows the [[manual:Palettes#Global_Macro_Palette|Global Macro Palette]].

The //Hide Global Macro Palette// action hides it.

The //Toggle Global Macro Palette// action shows it if it is hidden and hides it if it is visible.
