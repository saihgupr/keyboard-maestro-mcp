The Set Keychain Password to Text or Variable actions set a generic password in the keychain to a value.

:!: This action does //not// work with Internet Passwords – only with Generic Passwords.

The Set Keychain Password to Variable action has the placeholder text //%Variable%Variable Name%// already entered in the //to text// text area.


{{:action:setkeychainpasswordtovariable.png|}}


Text areas in these two actions can be set by typing a value or by selecting a value from the arrow at the right-hand end of the text area.

You must supply:
  *The name of the keychain item.
  *The account able to use that password.
  *The password to be entered into the keychain.
