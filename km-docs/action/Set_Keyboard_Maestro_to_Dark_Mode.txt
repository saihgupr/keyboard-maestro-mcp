====== Set Keyboard Maestro Dark Mode ======

The //Set Keyboard Maestro to Dark Mode//, //Set Keyboard Maestro to Light Mode//, and //Toggle Keyboard Maestro Dark Mode// actions (v9.0+, OS X 10.14+) allows you to set the Keyboard Maestro appearance to the Light or Dark appearance.

The actions will have no effect in systems before OS X 10.14 Mojave.

{{ set-km-dark-mode.png?nolink&587x85 | Set Keyboard Maestro Dark Mode }}

Select from the pop-up to:
  * Set Keyboard Maestro to System Appearance
  * Set Keyboard Maestro to Dark Mode
  * Set Keyboard Maestro to Light Mode
  * Toggle Keyboard Maestro Dark Mode
