The Use Variable action allows you to use a variable to set the:

  *mouse location.
  *front window location.
  *front window size.
  *front window frame.
  *front window by name.
  *front window by name containing.
  *front window by name matching.
  *front application by name.
  *front application by name containing.
  *front application by name matching.
  *the system volume.

The various size and location fields can be [[manual:Calculations|Calculations]].
