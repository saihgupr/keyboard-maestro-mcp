====== Show a Specific Application Action ======

The Show a Specific Application action shows the specified application.

This action will make a hidden application and its windows visible again, but it will //not// bring that application to the front or otherwise activate it.

To //activate// an application see the [[action:Activate_a_Specific_Application|Activate a Specific Application action]].
