====== Stream Deck Show Alert ======

The //Stream Deck Show Alert// action (v9.0+) briefly shows an alert mark on a [[/Stream Deck]] button.

{{ stream-deck-show-alert.png?nolink&503x88 | Stream Deck Show Alert }}

You specify the Button ID of the button to display the alert mark on.  If two buttons have the same ID, both will show the marker.

The Button ID field is a token [[/Text_Fields|Text Fields]].
