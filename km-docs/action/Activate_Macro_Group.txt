====== Macro Group Activation Actions ======

Macro Groups can be configured to be activated in various ways (such as from the Status Menu or a hot key).  The *Activate Macro Group* action lets you control the activation explicitly (such as from another Macro Group palette).

You can configure the action in similar ways to the Macro Group configuration, specifically:

* Activate for one action.
* Activate.
* Deactivate.
* Activate/Deactivate (toggle).
* Show palette for one action.
* Show palette.
* Hide palette.
* Show/Hide palette (toggle).

If you are not showing/hiding a palette, you can optionally have a visual indication of the activation.

Remember that all macros within a Macro Group that is not active will not be available for use.  Also, remember that if you hide a palette, that is also deactivating the macro group.

(i) Note that activation state is a transient state, and is not the same as enabled state (which is semi-permanent and displays in the editor).  This action will not change the display in the editor even when it activates or deactivates the macro group.  See [[:Macro Activation]] for more information.
