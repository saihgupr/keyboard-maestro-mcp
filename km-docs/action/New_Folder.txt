====== New Folder Action ======

This action creates a new folder at a specified location.

Note: The path must be an absolute path (or a path relative to home ~).

You can optionally turn on *Create Intermediate* (v8+) in the gear BUTTON{{{⚙}}} menu to create parent directories as necessary.
