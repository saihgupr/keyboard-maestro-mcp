====== Prompt for Screen Rectangle Action ======

The *Prompt for Screen Rectangle* action allows you select an area (or optionally just a point) on the screen. By default, the area will always be a positive rectangle, but you can preserve negative values (and hence the direction of selection) using action (gear) ⚙ menu.

Returned values are in screen coordinates, relative to the top left corner of the main screen.
