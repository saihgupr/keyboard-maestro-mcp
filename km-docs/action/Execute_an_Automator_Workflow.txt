====== Execute Automator Workflow ======

The Execute Automator Workflow action executes a specified Automator Workflow.

Select the workflow by specifying its path. Click the File Chooser button to the right of the action to select an existing file on disk. Option-click on the File Chooser button to show the currently selected file in the Finder (assuming it exists already).
