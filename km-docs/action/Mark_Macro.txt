The //Mark Macro action// allows you to “mark” a macro.  A marked macro shows up in the status menu with a tick mark next to it, or in a toolbar with a tick on it.  This can be useful to convey the state of the macro or whatever it controls.

The action allows you to:

* mark a macro.
* unmark a macro.
* toggle the mark of a macro.
