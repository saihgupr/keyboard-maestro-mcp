====== JSON Keys ======

The //JSON Keys collection// (v9.0+) lists all the keys from a JSON dictionary.

{{ json-keys.png?nolink&591x279 | JSON Keys }}

The index value can be any of:

* The key
* The strict key (a double quoted, escaped JSON string)
* The JSON object value
* The Pretty JSON object value
