===== Dictionary Token =====

The `%Dictionary[<Dict>,<Key>]%` token (v8+) allows you to access [[manual:Dictionaries|dictionary]] values in a [[:Text Fields |token text field]], where `<Dict>` is the name of the dictionary and `<Key>` is the key.
