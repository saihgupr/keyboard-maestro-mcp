====== CurrentTrack Token ======

The //CurrentTrack// token returns information about the current iTunes name.  You can ask for the:

* //%CurrentTrack%name%// - the current iTunes track name.
* //%CurrentTrack%artist%// - the current iTunes track artist.
* //%CurrentTrack%album%// - the current iTunes track album.
* //%CurrentTrack%ratingstars%// - the current iTunes song rating.
