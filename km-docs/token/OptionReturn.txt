====== OptionReturn Token ======

The //%OptionReturn%// token (v11.0+) can be used in an [[action:Insert_Text_by_Typing|Insert Text by Typing]] action to type an Option Return character. Anywhere else it will display as a unusual character (䷗) which hopefully no one ever tries to type.
