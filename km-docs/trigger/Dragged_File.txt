====== Dragged File Trigger ======

The *Dragged File trigger* executes when a file or folder is dragged on to a macro in a macro palette.

The path of the dragged file is available via the [[token:TriggerValue|TriggerValue token]].

You could use this trigger to perform actions on files or folders, or you can use it in combination with the [[action:Apply Modifiers to a Specific Application|Apply Modifiers to a Specific Application]] or [[action:Open_a_File_Folder_or_Application|Open a File Folder or Application]] action action to have the file opened in an application.
