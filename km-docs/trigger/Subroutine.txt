====== Subroutine Trigger ======

The *Subroutine trigger* (v10+) lets you execute a macro using the [[action:Execute_a_Subroutine|Execute a Subroutine]] action. This trigger defines the parameters that can be passed to the macro, and the variables they are stored in, as well as whether the macro returns a result.
